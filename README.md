# Python_task_bot
Это бот для тренировка Python на написание задач

### Версия бот 1 умеет:
- `/start` - бот здоровается и объясняет, что умеет
- `/complexity` - выбираем(при первом запуске)/меняем уровень сложности задач
- `/help` - все команды
- `/begin` - начать решать, бот отправяет тебе задачу
- Далее бот проверяет задачу и пишет правильно ли она выполнена

### Решения принятые в ходе обсуждения:
- Задачи будут хранится в базе и браться для пользователей будут тоже из базы
- В первой версии пользоваться может ограниченный круг лиц, потому что я еще не разбирался с песочницами.
- Общение с пользователем будет хранится в JSON файле, потому что с SQLite я еще не разбирался. Сохраняются:
    - Уровень сложности
    - Какие задачи выполнял уже и с каким результатом 
- Для каждой задачи в базе будут тесты, по которым бот будет определять правильно ли выполнена задача
- Запуск идет отдельно и живет в одной функции
- Запуск ограниче по времени
- Задачи хранятся в JSON файле, потому что с SQLite я еще не разбирался. Задачи состоят из:
    - id
    - Уровень сложности
    - Условие
    - Имя функции
    - Тесты (вход и ожидаемый выход)
